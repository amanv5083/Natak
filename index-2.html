About this hub

This is a static website made for GitHub Pages. It does not need PHP, MySQL or a server backend. The practical index is searchable, and the original PDFs are included in the same repository. Practical titles and page references are based on the supplied practical files; use the PDF for the complete original code, screenshots and output.

Note: PDF viewing depends on the browser's built-in PDF viewer. If the embedded preview does not load on a device, use “Open PDF”.
